# Shop artwork

The shop uses one original illustration atlas generated with the built-in image-generation tool. It is not product photography. The CSS displays each of its 16 equal cells in the corresponding prize card and collection item.

Prompt: Create a square 4x4 sprite sheet with isolated, polished 3D product illustrations on a consistent ivory-white background. Row 1: ICE BREAKERS Coolmint, Wintergreen, Cinnamon, EXTRA Spearmint. Row 2: EXTRA Peppermint, Polar Ice, GUI GUI pink slime, purple slime. Row 3: strawberry keychain, pastel star keychain, DUM DUMS cherry, blue raspberry. Row 4: pink journal, lavender journal, rainbow gel pens, classic yo-yo. No grid lines, no cell captions, no emoji styling. Center every item with generous margins.

All products in this arcade are virtual collectibles. Ticket costs are game values, not monetary prices.
